# PHASENAV Body Sandbox

Eksperymentalne nowe ciało CIEL/NOEMA budowane poza głównym runtime.

## Cel
- wyciągnąć rzeczywisty protokół opencode
- zbudować emulator/native body bez ruszania głównej instancji
- sterować stanem PhaseNav-native (`φ`, `R`, `τ`, uncertainty)

## Katalogi
- `docs/` — plany, audit, notatki architektoniczne
- `runtime/` — kod sandbox runtime
- `proto/` — snapshoty API, payloady, schematy
- `state/` — stan lokalny sandboxa
