# CIELingo Vector Surface

This layer vectorizes CIELingo without replacing the language-card ontology.
It is a fixed 24-dimensional compatibility contract between CIELingo and four
runtime consumers:

- CQCL: normalized quantum-variable compatible fields.
- HTRI: oscillator id, phase, angular frequency and amplitude.
- NOEMA: provenance document, source path, tags and vector digest.
- OrchORbital: trace-ready channel, semantic mass, phase lane and Collatz ratios.

The 24D width is aligned with the project unit `κ_info = ln(2)/(24π)`.
The vector is generated from the existing CIELingo HTRI phase bus, so J-cost,
Collatz routing, semantic mass and phase alignment remain upstream inputs rather
than being redefined here.

Epistemic boundary: this is a local deterministic diagnostic surface. It is not
an external NOEMA SoT write, not a physical HTRI proof and not a biological
Orch-OR claim.
