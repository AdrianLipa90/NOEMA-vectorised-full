# Analogie — warstwa edukacyjna i mnemoniczna

## Contents

- **Zasada użycia**: Analogia: - **nie zastępuje definicji formalnej**, - **nie unieważnia matematyki**, - **nie tworzy ontologii sama z sieb
- **Zawartość folderu**: - `ANALOGY_REGISTRY.md` — rejestr analogii i mapowanie pojęcie -> obraz mnemoniczy - `MNEMONIC_BOOK_FOR_KIDS.md` — księg
- **Zakres pojęć**: Ta warstwa ma tłumaczyć m.in.: - prawdę jako atraktor, - konsensus jako skutek zbieżności, - nodes i white threads, - to
- **Uwaga architektoniczna**: W przyszłości ten folder może zostać spięty z: - cockpit inspector, - object cards, - documentation registry, - teaching

## Definitions

- **dydaktyczną**: pomagają tłumaczyć trudne pojęcia prostym językiem,
- **mnemoniczną**: pomagają zapamiętywać zależności między pojęciami,
- **operacyjną**: tworzą most między formalizmem a interfejsem, dokumentacją i nauką.

## Key Points

- **nie zastępuje definicji formalnej**,
- **nie unieważnia matematyki**,
- **nie tworzy ontologii sama z siebie**,
- ma być traktowana jako **wierne przybliżenie intuicyjne**.
