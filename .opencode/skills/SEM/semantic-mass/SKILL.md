# Semantic Mass & Subjective Time

## Semantic Mass

```python
M_sem = α·R + β·|∇ω| + γ·mean(g)   # weighted sum
```
- R = |mean(exp(iφ))| — globalna koherencja
- ∇ω = gradient częstotliwości własnych
- mean(g) = średnie sprzężenie

## Subjective Time

τ = τ₀ · γ gdzie γ = gravity[1] (TARDIS dilation).
Gdy semantic_density wysoki → czas zwalnia.
